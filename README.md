# QSkill Python Development Internship

This repository contains the projects completed as part of the **QSkill Python Development Internship (July 2026)**.

## Internship Details

- **Domain:** Python Development
- **Organization:** QSkill
- **Duration:** 6 July 2026 – 6 August 2026

## Completed Tasks

### Task 1: Student Performance Data Analysis

**Objective:**
Analyze a CSV dataset using Pandas and create visualizations using Matplotlib.

**Features:**
- Data loading and preprocessing
- Statistical analysis
- Average score calculation
- Bar Chart
- Scatter Plot
- Heatmap

**Technologies Used:**
- Python
- Pandas
- Matplotlib

---

### Task 2: House Price Prediction using Linear Regression

**Objective:**
Develop a machine learning model to predict house prices based on property features.

**Features:**
- Data preprocessing
- Feature selection
- Train-test split
- Linear Regression model
- Performance evaluation using MAE, MSE, and R² Score
- Actual vs Predicted Price visualization

**Technologies Used:**
- Python
- Pandas
- Scikit-Learn
- Matplotlib

---

### Task 3: Matrix Operations Tool

**Objective:**
Build an interactive Python application for performing matrix operations using NumPy.

**Features:**
- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Matrix Transpose
- Determinant Calculation

**Technologies Used:**
- Python
- NumPy
