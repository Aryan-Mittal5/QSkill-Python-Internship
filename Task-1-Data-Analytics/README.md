# Student Performance Data Analysis

## Objective
Analyze student performance data using Pandas and visualize insights using Matplotlib.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
Student Performance Dataset

## Analysis Performed
- Loaded CSV data
- Calculated average math score
- Generated bar chart
- Generated scatter plot
- Generated heatmap

## Visualizations

### Bar Chart
Displays the Math marks of each student.

### Scatter Plot
Show the relationship between Math and Science marks.

### HeatMap
Displays the correlation between math,science and english marks.

## Observations

- The average Math marks are calculated using Pandas.
- The bar chart helps compare student performance.
- The scatter plot shows the relationship between Math and Science scores.
- The heatmap indicates the correlation among different subjects.
