# House Price Prediction using Linear Regression

## Objective
To predict house prices using machine learning and Linear Regression.

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- Matplotlib

## Dataset
House Price Dataset containing 4600 records.

## Features Used
- Bedrooms
- Bathrooms
- Sqft Living
- Sqft Lot
- Floors
- Waterfront
- View
- Condition
- Sqft Above
- Sqft Basement
- Year Built
- Year Renovated

## Model
Linear Regression

## Evaluation Metrics
- MAE: 210907.95
- MSE: 98691835089.62
- R² Score: 0.0323

## Output
The model predicts house prices based on property features.
